# Google Docs – Collaborative Document Creation

## Introduction

Google Docs is a cloud-based word processing tool provided by Google Workspace. It allows users to create, edit, format, and share documents online. It also supports real-time collaboration, making it useful for academic assignments, reports, project documentation, and teamwork.

As part of the Technical Writing (TW) course, I learned about the different features of Google Docs and how to create well-structured documents while collaborating with others.

## Topics Covered

### 1. Introduction to Google Docs
- Understanding Google Docs and its applications.
- Creating and editing documents online.
- Understanding cloud-based document creation and storage.

### 2. Creating and Structuring Documents
- Creating a new blank document.
- Using built-in templates for reports and meeting notes.
- Organizing content using headings and sections.
- Inserting tables, lists, images, footnotes, and equations.

### 3. Paragraph Styles and Formatting
- Using Title, Subtitle, Heading 1, and other heading styles.
- Formatting text and paragraphs.
- Maintaining consistent document appearance.
- Creating an automatic Table of Contents using heading styles.

### 4. Collaboration and Sharing
- Sharing documents through email invitations or links.
- Assigning Viewer, Commenter, and Editor permissions.
- Collaborating with multiple users in real time.
- Adding and resolving comments.
- Using Suggesting mode to track proposed changes.

### 5. Version History and Recovery
- Understanding automatic saving in Google Docs.
- Viewing previous document versions.
- Restoring earlier versions of a document.
- Naming important versions for future reference.

### 6. Images, Drawings, and Diagrams
- Inserting images from a computer, Google Drive, web, or Photos.
- Creating simple diagrams using the built-in Drawing tool.
- Using shapes, arrows, and other visual elements.
- Integrating external diagramming tools.

### 7. Tables and Lists
- Creating and formatting tables.
- Organizing information using bulleted and numbered lists.
- Creating checklists for tasks and collaborative work.

### 8. Equations and Code Snippets
- Inserting mathematical equations using the Equation tool.
- Writing mathematical expressions using LaTeX-style syntax.
- Formatting code snippets using monospace fonts.

### 9. Templates and Formatting Tools
- Using built-in document templates.
- Customizing headers and footers.
- Adding page numbers.
- Using Find and Replace, spelling, and grammar tools.

### 10. Citations and Bibliography
- Adding references using the Citations tool.
- Understanding MLA, APA, and Chicago citation styles.
- Inserting in-text citations.
- Automatically generating bibliographies.
- Understanding integrations with Zotero and Mendeley.

### 11. Exporting and Publishing
- Downloading documents in PDF, DOCX, ODT, HTML, and other formats.
- Publishing documents to the web.
- Integrating Google Docs with other Google Workspace applications.

### 12. Security and Permissions
- Managing document-sharing permissions.
- Controlling access to shared documents.
- Setting expiration dates and removing access.
- Understanding data protection and sharing controls.

### 13. Integration with Other Tools
- Integrating Google Docs with Google Drive, Calendar, Meet, and Forms.
- Connecting project management and diagramming tools.
- Understanding automation using Google Apps Script.

### 14. Best Practices
- Maintaining consistent formatting and document styles.
- Organizing documents using headings and a Table of Contents.
- Managing comments and suggestions.
- Reviewing document history and maintaining backups.

## Learning Outcome

Through this topic, I learned how to create, format, organize, and share professional documents using Google Docs. I also gained an understanding of real-time collaboration, version history, document permissions, citations, and exporting documents in different formats.
