# LaTeX – Technical Writing

## Introduction
LaTeX is a document preparation system widely used for creating professional documents, academic reports, research papers, and technical documentation. It is particularly useful for writing mathematical equations, scientific expressions, tables, and structured documents.

This section documents the concepts and practical applications of LaTeX that I learned as part of my Technical Writing (TW) course.

## Topics Covered

### 1. Basic Structure of LaTeX
- Understanding the basic structure of a LaTeX document.
- Use of `\documentclass`, `\begin{document}`, and `\end{document}`.
- Understanding the preamble and document body.
- Using packages and basic commands.

### 2. Mathematical Equations
- Writing mathematical expressions and equations.
- Fractions, square roots, subscripts, and superscripts.
- Summations, integrals, and other mathematical symbols.
- Inline and displayed equations.

### 3. Special Characters
- Using reserved characters such as `#`, `$`, `%`, `&`, `_`, `{`, and `}`.
- Understanding how to display special characters using escape sequences.

### 4. Matrices and Arrays
- Creating matrices using different environments.
- Using `matrix`, `pmatrix`, `bmatrix`, and other matrix formats.
- Creating mathematical arrays and aligning expressions.

### 5. Mathematical Display Styles
- Understanding different mathematical display styles.
- Using `\displaystyle`, `\textstyle`, `\scriptstyle`, and `\scriptscriptstyle`.
- Understanding how mathematical expressions are rendered in different styles.

### 6. Tables
- Creating tables using the `tabular` environment.
- Row and column alignment.
- Using horizontal and vertical lines.
- Adding captions and formatting tables.

### 7. Colours
- Applying colours to text and document elements.
- Using the `xcolor` package.
- Defining custom colours and highlighting content.

### 8. Figures and Pictures
- Inserting images into LaTeX documents using `\includegraphics`.
- Resizing and positioning images.
- Adding captions and labels to figures.
- Understanding figure placement.

### 9. Bibliography and References
- Creating bibliographies and reference lists.
- Using `\cite` and `\bibitem`.
- Understanding citations and referencing in academic documents.

### 10. Other Important Concepts
- Text formatting: bold, italic, and underline.
- Creating ordered and unordered lists.
- Sections and subsections.
- Labels and cross-referencing.
- Page formatting and margins.
- Using commonly required LaTeX packages.

## Learning Outcome
Through these concepts and practical exercises, I learned how to create structured, well-formatted technical documents using LaTeX. I also gained experience in writing mathematical expressions, inserting figures, designing tables, and managing references in academic documents.
