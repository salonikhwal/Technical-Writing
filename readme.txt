# Technical Writing Lab – Documentation

## About This Repository

This repository contains documentation of the concepts, tools, and practical skills I learned as part of the **Technical Writing (TW)** course at Malaviya National Institute of Technology (MNIT), Jaipur.

The repository covers various tools used for technical documentation, presentation creation, collaborative document editing, automated code documentation, and version control.

## Topics Covered

### 1. LaTeX
LaTeX is a document preparation system used to create professional technical and academic documents.

**Concepts Learned:**
- Basic structure of a LaTeX document.
- Mathematical equations and special characters.
- Matrices, arrays, and mathematical display styles.
- Creating and formatting tables.
- Applying colours and inserting figures and pictures.
- Bibliography and references.
- Text formatting, lists, packages, and page formatting.

[Explore LaTeX Documentation](./LaTeX/README.md)

### 2. Beamer
Beamer is a LaTeX document class used to create slide-based presentations.

**Concepts Learned:**
- Basic structure of a Beamer document.
- Using `\documentclass{beamer}`.
- Creating slides using the frame environment.
- Adding titles to slides.
- Creating bullet points using the `itemize` environment.
- Organizing content across multiple slides.

[Explore Beamer Documentation](./Beamer/README.md)

### 3. Doxygen
Doxygen is an automated documentation generator that extracts documentation from specially formatted comments in source code.

**Concepts Learned:**
- Introduction and installation of Doxygen.
- Creating and configuring a Doxyfile.
- Writing documentation comments.
- Using Doxygen tags such as `\brief`, `\param`, and `\return`.
- Documenting functions and classes.
- Generating HTML and PDF documentation.
- Understanding diagrams and documentation output formats.

[Explore Doxygen Documentation](./Doxygen/README.md)

### 4. Google Docs
Google Docs is a cloud-based word processing application used to create, edit, format, and share documents.

**Concepts Learned:**
- Creating and structuring documents.
- Text formatting and paragraph styles.
- Tables, lists, images, and equations.
- Real-time collaboration and document sharing.
- Comments and Suggesting mode.
- Version history and document recovery.
- Citations and bibliography.
- Exporting documents into different formats.
- Document permissions and security.

[Explore Google Docs Documentation](./Google-Docs/README.md)

### 5. Git
Git is a distributed version control system used to track changes in files and manage project history.

**Concepts Learned:**
- Introduction to version control and Git architecture.
- Installing and configuring Git.
- Creating and managing repositories.
- Working directory, staging area, and local repository.
- Tracking changes and creating commits.
- Viewing and comparing changes.
- Branching, switching, and merging.
- Undoing changes and using Git stash.
- Remote repository operations.
- Tags, releases, and Git best practices.

**Important Git Commands:**

```bash
git init
git status
git add .
git commit -m "message"
git log
git diff
git branch
git switch
git merge
git stash
git clone
git push
git pull
git fetch
git remote -v
```

[Explore Git Documentation](./Git/README.md)

### 6. GitHub
GitHub is a web-based platform used to host Git repositories and collaborate on software development projects.

**Concepts Learned:**
- Creating and managing GitHub accounts.
- Creating public and private repositories.
- Understanding README files.
- Connecting local repositories to GitHub.
- Uploading and cloning projects.
- Branches and collaborative development.
- Pull requests and code reviews.
- Forking repositories.
- GitHub Issues and Projects.
- GitHub Actions.
- Tags, releases, and repository security.

[Explore GitHub Documentation](./GitHub/README.md)
